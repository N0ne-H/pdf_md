**Goal:** Resolve Windows concurrent PNG publication/read failures while preserving complete files, names, cleanup and real error reporting.

**Architecture:** Preserve the closed-temporary-file publication path. Windows no-overwrite rename prevents replacing a published winner; Windows read-only CreateFileW with read/write/delete sharing avoids CRT's incompatible sharing while a publisher still holds DELETE access. Change only render publication/cache reads and focused regression tests; no retries.

A real handle with DELETE access and shared reads deterministically rejects the old CRT read. Add this regression (fails before the read fix) and its exclusive-lock counterpart (must continue to fail visibly). This changes handle sharing, not ACLs or sandbox policy. The initial hypothesis alone was insufficient; its logs remain under rename-only-logs.
